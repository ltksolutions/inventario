## Čo bolo implementované

### K5 — Routes (4 endpointy)

Nový plugin `apps/api/src/modules/protocols/protocols.routes.ts`:

- **`GET /v1/loans/:id/protocols`** — zoznam protokolov k výpožičke. RBAC: borrower daného Loan ALEBO ASSET_MANAGER/ADMIN. Cross-tenant izolácia: loan lookup cez `organisationId` z auth tokenu. Dependency: `loan-requests-routes`.
- **`GET /v1/protocols/:protocolId`** — metadata protokolu (JSON). RBAC: účastník protokolu (handover alebo receive `userId`) ALEBO ASSET_MANAGER/ADMIN.
- **`GET /v1/protocols/:protocolId/pdf`** — on-demand PDF render. Načíta `Organisation` pre logo + identitu, volá `loadLogo()` + `loadDefaultFont()` (mimo transakcie — bezpečné), vyrenderuje cez `renderProtocolPdf()`. Lazy `pdfSha256` — dopočíta + uloží po prvom stiahnutí (background, neblokuje response). Vracia `application/pdf` s `Content-Disposition: inline`.
- **`POST /v1/protocols/:protocolId/sign`** — K6 (viď nižšie).

**Wiring:**

- `LoansService.setProtocolsRepo(repo)` — nová public metóda, zavolaná z `protocols-routes` pluginu po `ensureIndexes()`. Riešenie chicken-egg problému: `LoansService` je dekorovaný v `loan-requests-routes` (bez repo), `protocols-routes` ho injektnú neskôr.
- `LoanProtocolsRepository.ensureIndexes()` volaný v `protocols-routes` plugin startup.
- `protocolsRoutes` zaregistrovaný v `server.ts` po `loansRoutes`.

### K6 — Podpis (CLICK_TO_SIGN)

`POST /v1/protocols/:protocolId/sign` endpoint:

- RBAC: len priamy účastník protokolu (handover alebo receive `userId === actorId`). Manager bez priamej účasti nemôže podpísať.
- Zakazuje podpis SIGNED protokolu → 403.
- Zakazuje duplicitný podpis tej istej strany → 403.
- Pri obojstrannom podpise: prechod `DRAFT → SIGNED`, render PDF s novými podpismi, SHA-256 dopočítaný + fixovaný na záznamu.
- IP adresa normalizovaná (IPv4-mapped IPv6 `::ffff:x.x.x.x` → `x.x.x.x`).

## Kľúčové rozhodnutia tejto session

- **`setProtocolsRepo()` injection pattern** — `LoansService` vzniká v `loan-requests-routes` (bez repo), `protocols-routes` ho dodá neskôr. Alternatíva (konštruktor) by vyžadovala reorder pluginov alebo duplicate registration. Injection cez public metódu je minimálna zmena.
- **PDF endpoint bez response Zod schema** — Fastify nesmie serializovať binary stream; `schema: { params: ... }` bez `response` je správny pattern pre file endpoints.
- **Manager nemôže podpísať za inú stranu** — konzervatívne rozhodnutie: podpis má právnu hodnotu, musí ho urobiť skutočný účastník. Manager vie schváliť a vydať, ale nie podpísať za borrowera. Manager môže byť přirozenou stranou protokolu (napr. je aj handover).
- **Borrower snapshot prázdny ostáva** — K4 kompromis zachovaný. K5 ho nedoplnil (rozhodnutie: nepridávať DB lookup do existujúcej cesty, snapshot ostáva prázdny v DRAFT). Podpísaný protokol (SIGNED) má strany zachytené v čase podpisu.
