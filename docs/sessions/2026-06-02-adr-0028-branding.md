## Čo bolo implementované

### Fáza 1 — Schéma + backend (B1–B4)

**B1 — Schéma zjednotenie**

- `HexColorSchema` extrahovaný do `packages/shared-types/src/schemas/common.ts` (vedľa `EmailSchema`, s `.describe()`)
- `OrganisationBrandKitSchema` v `organisation.ts`: 4× inline hex regex → `HexColorSchema`, pridaný `logoDot: HexColorSchema.nullable().default(null)`
- `BrandKitBodySchema` v `organisations.routes.ts`: zladený (pridaný `logoDot`)
- `packages/design-tokens/src/brand-kit.schema.json`: prepísaná na ploché polia zodpovedajúce Zod tvaru, pridaný `$comment` (build-time referencia), `$id` opravený na `inventario.estate`, odstránené `tenantId/version/metadata/colors.*/typography.*`
- Shared-types build + JSON schema regen: `logoDot` a `ORGANISATION_BRANDING_UPDATED` prítomné v dist

**B2 — WCAG kontrast util**

- `apps/api/src/lib/contrast.ts`: `relativeLuminance()`, `contrastRatio()`, `meetsWcagAA()` — sRGB linearizácia IEC 61966-2-1 (exponent 2.4), zaokrúhlenie na 2 desatinné miesta
- 21 unit testov `tests/unit/contrast.test.ts` — hraničné páry, Inventario Navy/Blue, SFZ farby, `#767676` boundary
- Kľúčové zistenie: Inventario Blue `#388fc3` na bielej = **3.57:1** (pod AA) — relevantné pre B3 validáciu

**B3 — Backend PATCH validácia**

- `ORGANISATION_BRANDING_UPDATED` pridaný do `AuditLogSchema.action` enum (shared-types)
- `audit.service.ts`: mapping pre nový action (`legalBasis: contract`, `dataCategories: ['audit_metadata']`)
- `UpdateOwnOrganisationBodySchema` rozšírená o `brandKit: BrandKitBodySchema.nullable()`
- `organisations.service.ts` — `updateCurrent()` rozšírený o validáciu **pred** transakciou:
  1. **Plán gating**: FREE + akýkoľvek farba/font/logoDot → 403 s textom „dostupné v Pro"
  2. **WCAG**: `primary`+`primaryFg` pár pod 4.5:1 → 400 s pomerom; totéž pre `accent`+`accentFg`
  3. **Logo SVG**: `logoUrl` končiaci `.svg` alebo `.svg?` → 400
  4. **Audit**: branding-only patch → `ORGANISATION_BRANDING_UPDATED`; kombinovaný → `ORGANISATION_UPDATED`
- Importy: `ForbiddenError`, `contrastRatio`, `meetsWcagAA`

**B4 — Integračné testy**

- `tests/integration/organisations-branding.test.ts`: 21 testov
  - FREE: logo OK, null OK, farby/font/logoDot → 403
  - SVG: `.svg` → 400, `.svg?` → 400, `.png` OK, `.jpg` OK
  - Pro: happy path (primary, accent, font, logoDot, celý kit), WCAG odmietnutia (primary pár, accent pár), jeden field bez páru OK, ENTERPRISE OK
  - Audit: `ORGANISATION_BRANDING_UPDATED` (branding-only), `ORGANISATION_UPDATED` (kombinovaný)
- Bug opravený počas testov: kolekcia `audit_log` vs `audit_logs` (správna je s `s`)

### Fáza 2 — Runtime brand injekcia (B5–B6)

**B5 — BrandProvider**

- `apps/web/src/lib/BrandProvider.tsx`: nový `'use client'` komponent
  - `useEffect` sleduje `activeMembership` + `availableOrganisations` (z `AuthProvider`)
  - Nastaví `document.documentElement.setAttribute('data-tenant', slug)` po vyriešení aktívneho tenanta
  - Vstrekne `<style id="inv-tenant-brand">` s `--inv-brand-*` CSS premennými (+ `--inv-font-family-sans` ak zadaný)
  - `logoDot`: ak null, fallback na `accent`; ak accent tiež null, nič nevstrekne
  - Čistenie: keď `brandKit` null → `removeAttribute('data-tenant')` + vyprázdni style blok
  - Exportovaná čistá funkcia `buildBrandStyle(slug, brandKit)` — testovateľná bez DOM
- `apps/web/src/app/providers.tsx`: `<BrandProvider>` obalí `children` vo vnútri `<AuthProvider>`
- `AvailableOrganisation.brandKit: unknown` → pretypovaný na inline struct (vyhnuto import/order ESLint konfliktu medzi external/internal type skupinami)
- `OrganisationSummary` + `UpdateCurrentOrganisationInput` v `organisations-hooks.ts`: pridaný `BrandKit` interface + `brandKit: BrandKit | null`

**B6 — Logo v AppShell**

- `apps/web/src/components/AppShell.tsx`:
  - `currentLogoUrl` z `activeOrg?.brandKit?.logoUrl ?? null`
  - Nový `TenantLogo` komponent: `next/image` s `unoptimized` (externé URL bez domain whitelist), `width={0} height={28}`, React `useState(errored)` fallback na `<Layers>` ikonu pri chybe načítania
  - Wordmark: keď `currentLogoUrl` → `<TenantLogo>` + skrytý `<Layers>`; keď null → `<Layers>` + `currentOrgName`
  - Vždy zobrazuje `currentOrgName` (nie statické „Inventario")

### Fáza 3 — Admin UI (B7–B8)

**B7 — Branding sekcia v /settings/organisation**

- `apps/web/src/components/OrganisationSettingsContent.tsx`:
  - Import `Lock`, `Palette` z lucide-react
  - Nové state premenné: `logoUrl`, `primary`, `primaryFg`, `accent`, `accentFg`, `logoDot`, `fontFamilySans`, `logoPreviewError`
  - Hydratácia z `org.brandKit` v `useEffect`
  - `buildBrandKit()` helper — zostaví payload pre PATCH
  - `brandKit: buildBrandKit()` pridaný do `update.mutate()`
  - Nová `<section>` „Branding" za QR sekciou:
    - Logo URL input + live náhľad `<img>` s `onError` fallback text
    - FREE plán: farebná oblasť zamknutá s `<Lock>` ikonou + mailto CTA na Pro
    - Pro+: color picker + hex text input pre každú farbu, font text input
    - Live náhľad CTA tlačidiel s inline štýlmi zo zadaných farieb

**B8 — Kontrast indikátor**

- `hexContrast(hex1, hex2)` — frontend kópia algoritmu z `contrast.ts` (identická logika, bez imports)
- `HEX_RE = /^#[0-9a-fA-F]{6}$/` — guard pre validáciu
- `ContrastBadge({ fg, bg })` komponent — zobrazí `✓ X:1` (zelené) alebo `✗ X:1` (červené) pod farebnými pármi
- Indikátory pod primárnym párom aj akcentovým párom
- Renderuje sa len keď oba hex stringy sú platné #RRGGBB

## Kľúčové zistenia a rozhodnutia

| #   | Zistenie                                                                                                                                                                                 |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `HexColorSchema` → `common.ts` (nie `organisation.ts`) — konvencia repa (reusable primitív vedľa `EmailSchema`)                                                                          |
| 2   | `brand-kit.schema.json` nebol importovaný za behu — len build-time referencia v `package.json` exports; zladená, nie zhodená                                                             |
| 3   | Inventario Blue `#388fc3` na bielej = **3.57:1** (pod AA) — default brand kit sa cez `/current` PATCH nepošle (null = default), validácia sa nezapne                                     |
| 4   | Kontrast testy: moje WebAIM referencie boli nepresné; opravené podľa reálneho algoritmu (reálny Navy = 13.9:1, Blue na bielej = 3.57:1)                                                  |
| 5   | `AvailableOrganisation.brandKit: unknown` pretypovaný ako inline struct (nie import z `organisations-hooks`) — vyhnuto `import/order` ESLint konfliktu external vs internal type skupiny |
| 6   | `audit_log` vs `audit_logs` — kolekcia má `s` na konci; bug v testoch opravený                                                                                                           |
| 7   | `next/image` s `unoptimized` pre externé logo URL (v1 = URL na cudzom hostingu; v2 Blob upload = domain whitelist možný)                                                                 |
| 8   | ESLint config web nemá `@next/next` plugin — `eslint-disable-next-line @next/next/no-img-element` nefunguje; logo preview v settings používa natívny `<img>` (OK, nie production render) |
