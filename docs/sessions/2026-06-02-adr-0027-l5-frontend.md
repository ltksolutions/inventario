## Čo bolo implementované

### Nové komponenty

**`LabelPrintButton.tsx`** — tlač štítka pre jeden asset (detail page):

- PDF mód: `window.open` na `GET /v1/labels/sheet?assetIds=:id` → OS tlačový dialóg
- ZPL mód: fetch ZPL z `GET /v1/assets/:id/label?format=zpl` → Zebra Browser Print agent (localhost:9100)
- Browser Print fallback: timeout 2s → chybová správa + ponuka PDF fallback
- Mód sa určuje z `organisation.labelPrinting.mode` (null/PDF_SHEET → PDF, ZEBRA_ZPL → ZPL)

**`BatchLabelPrintButton.tsx`** — dávková tlač zo zoznamu assetov:

- Preset dropdown (Avery L7160 / L7163) pre PDF mód
- ZPL mód: POST batch → sekvenčná tlač cez Browser Print agent
- Max 200 assetov (backend limit), warning ak viac vybraných
- PDF fallback pri ZPL chybe

### Zapojenie do existujúcich komponentov

- `useCurrentOrganisation()` hook pre `labelPrinting.mode`

## Kľúčové rozhodnutia

- **Browser Print localhost:9100** — bez CORS problémov (same-origin pre agenta na localhost). HTTP (nie HTTPS) — agent počúva na oboch portoch, HTTP je jednoduchší pre interný localhost.
- **Selekcia cez "Vybrať všetky na strane"** — jednoduchší UX ako per-row checkboxy (nevyžaduje zmenu `AssetsTable`). Výber pretrváva cez stránky — používateľ môže vybrať stránku 1, prejsť na stránku 2, vybrať stránku 2, a tlačiť všetky naraz.
- **`window.open` pre PDF** — prehliadač automaticky zachytí PDF a zobrazí tlačový dialóg; žiadne blob handling, žiadne CORS problémy.
- **Fallback na PDF pri ZPL chybe** — agent nebeží / tlačiareň nedostupná → jednoduchý fallback, nie "dead end".
