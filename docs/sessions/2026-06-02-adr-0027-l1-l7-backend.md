## Čo bolo implementované

### L1 — Schéma + org-create cesty

`OrganisationLabelSettingsSchema` pridaná do `packages/shared-types/src/schemas/organisation.ts`:

- `mode: 'PDF_SHEET' | 'ZEBRA_ZPL'` (default PDF_SHEET)
- `pdfPreset: 'avery-l7160' | 'avery-l7163'` (default avery-l7160)
- `zplLabelWidthMm`, `zplLabelHeightMm`, `zplDpi` (203|300), `zplDarkness` (0–30)
- `finderText: { enabled, text }` — sprievodný text pre nálezcu, default vypnutý

`labelPrinting: null` doplnené do všetkých 4 org-create ciest:

- `organisations.service.ts` → `buildOrganisationFromClaims` (JIT)
- `registration.routes.ts` → email register
- `oauth.routes.ts` → SSO self-serve
- `tests/helpers/test-fixtures.ts` → `resolveTestTenantId` + `seedTestTenant`

### L2 — `renderLabelSheetPdf`

`apps/api/src/modules/labels/label-sheet-renderer.ts`:

- Avery L7160 (3×8=24/A4, 63.5×38.1 mm) a L7163 (2×7=14/A4, 99.1×38.1 mm)
- Každý štítok: QR (error correction H) + inventoryNumber + názov + finderText (opt-in)
- Voliteľné logo v strede QR (max 22 % strany — overený vzor)
- DejaVu Sans embed, diakritika SK ✓; ohraničujúci obdĺžnik (strihovacie vodiace linky)
- Deterministický render; QR doména z `appBaseUrl`; 409 ak chýba

### L3 — `renderLabelZpl`

`apps/api/src/modules/labels/label-zpl-renderer.ts`:

- Vlastný ZPL II builder, žiadny závis; čistá funkcia → deterministický string
- `^CI28` = UTF-8 → plná SK diakritika
- `^BQ` QR s `qrMag` odvodeným z DPI (203 dpi → mag 3, 300 dpi → mag 4)
- `^FD` text: inventoryNumber + názov + finderText (ak zapnutý)
- Rozmery a darkness z `organisation.labelPrinting` configu; defaults pre null config

### L4 — Routes

`apps/api/src/modules/labels/labels.routes.ts` + registrácia v `server.ts`:

- `GET /v1/labels/sheet?assetIds=...&preset=avery-l7160` → PDF hárok
- `GET /v1/assets/:id/label?format=zpl` → JSON `{ zpl }` pre jeden štítok
- `POST /v1/labels/zpl { assetIds: [...] }` → JSON `{ labels: [{ assetId, zpl }] }` pre dávku
- RBAC: EMPLOYEE+; on-demand, žiadna persistencia
- Batch ZPL: nenájdené assety sa preskočia (nespôsobia zlyhanie celého batchu)

## Kľúčové rozhodnutia tejto session

- **Logo v strede QR OK** — error correction level H (30 % redundancia) umožňuje až ~22 % prekryv bez straty čitateľnosti. Implementované v PDF aj ZPL (ZPL: logo sa nerenderuje priamo v ZPL — to patrí do Browser Print / frontend layer, L5).
- **ZPL batch nefailuje na nenájdených assetoch** — preskočí, vráti len nájdené. PDF sheet naopak failuje 404 (používateľ si explicitne vybral štítky a chce vedieť čo chýba).
- **finderText.text je nullable v DB** — Zod default zabezpečuje hodnotu, ale `?.text ?? ''` guard je všade kde sa text číta.
- **L5 (frontend) je v separátnej session** — backend endpointy sú plne funkčné a testovateľné cez Swagger/curl bez frontendu.
