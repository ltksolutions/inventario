## Kľúčové rozhodnutia tejto session

- **Logo fetch oddelený od renderera** — `renderProtocolPdf` dostane logo ako hotové bajty (`Uint8Array`); `loadLogo()` je samostatný helper. Výhoda: render je čistá funkcia bez sieťových volaní → deterministický test bez mockovania.
- **`protocolsRepo` je optional v `LoansService`** — existujúce integration testy (loans) netreba meniť; K5 routes vždy poskytnú inštanciu.
- **`paperSize` zatiaľ hardcoded `'A4'`** — K5 ho doplní z `org.protocolSettings?.paperSize ?? 'A4'` pri načítaní org v route handleri. K4 scope je čistý insert bez extra DB lookup.
- **Borrower snapshot prázdny** — `displayName: ''` a `email: ''` v HANDOVER protokole z `fulfilLoanRequest` a `createDirectLoan`. K5 to doplní po načítaní user dokumentu pred renderom; snapshot na zázname sa doplní pri signovaní (K6). Toto je zámerný kompromis — K4 nepridáva extra DB lookup do existujúcej transakcie.
