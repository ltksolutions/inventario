## Kľúčové rozhodnutia (MCP scope, locked v tejto rev)

Pravidlo zostáva: _„ak to LLM zavolá s vymyslenými parametrami, môže spôsobiť nezvratnú
škodu alebo únik dát? → web UI only."_ Z toho vyplýva, čo ostalo **mimo** MCP surface:

- **Podpis protokolu** (`POST /v1/protocols/:id/sign`) — právny úkon konkrétnej strany.
- **QR obrázok + štítky** (`/v1/assets/:id/qr`, `/v1/labels/*`) — binárne/PDF výstupy na tlač,
  patria do web UI; LLM ich ako tool nepotrebuje.
- **Verejný scan** (`GET /v1/public/scan/:token`) — neautentifikovaný lost-and-found, mimo
  autentifikovaného tenant-scoped MCP tokenu.
- **Stock reconcile** (`POST /v1/stock/:itemId/reconcile`) — ADMIN diagnostický opravný nástroj.

Rozhodnutia Q1–Q7 (remote HTTP/SSE, manual token → OAuth 2.1, single-tenant, curated tools,
read + non-destructive writes, API gateway, tools only) sa **nemenili**.
