### K3 — QR render endpoint (commit aktuálny)

**`apps/api/package.json`:**

- `qrcode: ^1.5.4` + `@types/qrcode: ^1.5.5`

**`assets.routes.ts` — nový endpoint:**

- `GET /v1/assets/:id/qr?format=svg|png`
- Auth: EMPLOYEE+ (rovnaké ako GET detail)
- format default `svg`; Content-Type `image/svg+xml` / `image/png`
- Cache-Control: `public, max-age=31536000, immutable` (token nemenný → QR stabilný)
- URL = `${org.appBaseUrl}/scan/${asset.publicToken}` — VÝLUČNE z DB, nikdy z Host hlavičky
- Ak `appBaseUrl` null → 409 s jasnou správou
- QR knižnica: `QRCode.toString(url, { type: 'svg' })` / `QRCode.toBuffer(url, { type: 'png' })`

## Klucove rozhodnutia a nalezy

- **Partial index vs sparse:** `publicToken_unique_partial` s `$type: string` — sparse by indexoval
  explicit `null` a zkolizoval pri viacerých null hodnotách (viacero assetov pred migráciou)
- **publicToken generácia pred transakciou vs v transakcii:** generujeme v transakcii — ak insert
  failne (unique kolízia na inventoryNumber), token sa zahodí a driver retry vygeneruje nový
- **appBaseUrl NIKDY z Host hlavičky:** doménová nezávislosť je tvrdá požiadavka ADR-0021 (forky)
- **qrcode knižnica:** čisto Node.js, žiadna canvas/browser závislosť → funguje na Vercel serverless
- **PhoneSchema import** chýbal v `organisation.ts` — rýchly fix
